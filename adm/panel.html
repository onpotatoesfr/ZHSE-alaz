A password-protected backup is safe to keep anywhere (email it to yourself, a USB stick). Without the password it is useless, so it never exposes the boards. On a new PC: open the panel, click Unlock with password, pick the file and type the password.

Keep the plain backup file private: anyone with it can control the boards. If it's ever lost or shared, make a new key and send the new code.
